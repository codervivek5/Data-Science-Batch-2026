## 🧠 Course Curriculum

### 🐍 Part 1: Python Programming (Zero to Advanced)

![Python for Data Science](https://files.realpython.com/media/Python-Data-Science_Watermarked.2789459dd138.jpg)

<details>
<summary><strong>Click to expand detailed modules</strong></summary>

- **Basics**: Installation, syntax, variables, data types, I/O, operators
- **Control Flow**: if-elif-else, loops, break/continue/pass, pattern printing
- **Data Structures**: List, Tuple, Set, Dictionary, strings, nested structures
- **Functions**: def, args/kwargs, lambda, recursion, scope
- **Modules & Packages**: import, built-ins, pip, virtual environments
- **Advanced**: File handling, exception handling, OOP (classes, inheritance, magic methods), decorators, generators, regex
- **Data Science Tools**: NumPy, Pandas, Matplotlib, Seaborn, statistics
- **Practical**: REST APIs, FastAPI basics, Git/GitHub, Selenium, mini projects

</details>

### 📊 Part 2: Data Science & Machine Learning

![ML Algorithms Visualization](https://towardsdatascience.com/wp-content/uploads/2024/03/1g1SoX7Hbh6vEdRGyQgcf7A.png)

<details>
<summary><strong>Click to expand detailed modules</strong></summary>

- Math foundations (statistics, probability, linear algebra)
- ML types: Supervised, Unsupervised, Reinforcement
- Regression: Linear, Polynomial, Random Forest, XGBoost
- Classification: Logistic, KNN, SVM, Naive Bayes
- Evaluation: MAE/MSE/RMSE, Accuracy/Precision/Recall/F1, ROC-AUC
- Unsupervised: K-Means, Hierarchical, DBSCAN, PCA
- Feature engineering, scaling, handling missing data/outliers
- Hyperparameter tuning (GridSearchCV), cross-validation

</details>

### 🧠 Part 3: Deep Learning (Industry-Level)

![Deep Learning Architectures](https://daxg39y63pxwu.cloudfront.net/images/blog/deep-learning-architectures/Deep_Learning_Architecture_Diagram__by_ProjectPro.webp)

<details>
<summary><strong>Click to expand detailed modules</strong></summary>

- Foundations: AI vs ML vs DL, neurons, forward/backward propagation
- Activation & loss functions, optimizers (Adam)
- Regularization: Dropout, L2, Batch Norm, Early Stopping
- CNNs: Convolutions, pooling, transfer learning (pretrained models)
- Sequence models: RNN, LSTM, GRU
- Transformers: Attention, self-attention, encoder-decoder architecture

</details>

### 🤖 Part 4: Generative AI & Agentic AI

![Generative AI Diffusion](https://cdn.prod.website-files.com/645cec60ffb18d5ebb37da4b/65f2b9d306dad77d174e4ab6_Picture3.jpg)

<details>
<summary><strong>Click to expand detailed modules</strong></summary>

- LLMs, tokens, transformers, diffusion models
- Prompt engineering (zero-shot, few-shot, templates)
- RAG systems: Embeddings, vector DBs (FAISS/Pinecone), building FAQ bots
- Agentic AI: Tool-using agents, memory, planner-executor
- Frameworks: LangChain, LlamaIndex
- Deployment: FastAPI + Docker basics, scaling

</details>
